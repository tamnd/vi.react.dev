<Intro>

Việc phát triển React được dẫn dắt bởi một đội ngũ tận tâm làm việc toàn thời gian tại Meta. Dự án cũng nhận được đóng góp từ mọi người trên khắp thế giới.

</Intro>

## React Core {/*react-core*/}

Các thành viên của nhóm React Core làm việc toàn thời gian trên các API thành phần cốt lõi, engine vận hành React DOM và React Native, React DevTools, cùng website tài liệu React.

Các thành viên hiện tại của nhóm React được liệt kê theo thứ tự bảng chữ cái bên dưới.
