<Intro>

React tích hợp với các công cụ như trình soạn thảo, TypeScript, tiện ích mở rộng của trình duyệt và compiler. Phần này sẽ giúp bạn thiết lập môi trường làm việc.

</Intro>

## Thiết lập trình soạn thảo {/*editor-setup*/}

Xem các [trình soạn thảo được chúng tôi khuyến nghị](/learn/editor-setup) và tìm hiểu cách cấu hình chúng để làm việc với React.

## Sử dụng TypeScript {/*using-typescript*/}

TypeScript là một cách phổ biến để bổ sung định nghĩa kiểu cho codebase JavaScript. [Tìm hiểu cách tích hợp TypeScript vào dự án React của bạn](/learn/typescript).

## React Developer Tools {/*react-developer-tools*/}

React Developer Tools là tiện ích mở rộng trên trình duyệt có thể kiểm tra component React, chỉnh sửa prop và state, cũng như xác định các vấn đề về hiệu năng. Tìm hiểu cách cài đặt [tại đây](learn/react-developer-tools).

## React Compiler {/*react-compiler*/}

React Compiler là một công cụ tự động tối ưu ứng dụng React của bạn. [Tìm hiểu thêm](/learn/react-compiler).

## Bước tiếp theo {/*next-steps*/}

Hãy chuyển đến hướng dẫn [Bắt đầu nhanh](/learn) để khám phá những khái niệm React quan trọng nhất mà bạn sẽ gặp hằng ngày.
